# First real community pilot

The demo is complete as a synthetic technical concept. A public-service pilot is a separate validation stage.

1. Recruit one community organisation and agree on a concrete decision: for example, identifying where a library outreach visit would be useful.
2. Ask what information they already use and whether distance mapping would change a decision. Stop or change direction if it adds no value.
3. Select one community and one service category. Agree the point-sampling method and exploratory thresholds; cite any actual standard separately.
4. Obtain data with confirmed publication and redistribution rights. Verify facilities within and around the boundary.
5. Run the analysis, record source versions and parameters, and inspect spatial outliers.
6. Review the map with residents and service operators. Record transport barriers, capacity, disability access and data omissions separately.
7. Test on a supported QGIS LTR and on physical iOS/Android devices before sharing the mobile concept publicly.
8. Publish only approved public data and explain limitations. Measure usefulness by corrected records, decisions supported and user feedback, not app downloads alone.

Initial success: an organisation can reproduce the map and describe one useful action it supported. No claim of improved service outcomes is warranted without follow-up evidence.
