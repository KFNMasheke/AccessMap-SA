# Security and privacy

This release runs locally, has no server, authentication, telemetry, public submissions or resident database. Bundled data is fictional. The mobile concept stores only facility bookmark IDs on-device in unencrypted app storage; do not use that storage for secrets or personal records.

Use the repository's private vulnerability reporting feature if enabled by its owner. Do not put sensitive details, credentials or resident information in a public issue. A dedicated disclosure inbox has not yet been established.

If hosted accounts, submissions or government integrations are proposed later, review threat models, data protection, access controls, tenant separation, auditability, rate limits, backup/restore and incident handling before implementation. Those features are outside this release.
