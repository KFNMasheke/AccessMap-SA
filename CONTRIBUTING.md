# Contributing

Open an issue describing the community decision your change supports before proposing a substantial feature. Small fixes and reproducible bug reports are welcome.

Keep the project offline and dependency-light. Prefer adapters and portable data packs over hosted infrastructure. Preserve the distinction between distance and practical accessibility. Never turn missing records into a claim of absence.

Run the Python tests, mobile model tests and available QGIS integration checks. For changes to calculation methods, include independent expected results. For UI work, verify small screens, empty/error states, readable contrast and keyboard or assistive-technology access.

Do not commit personal records, secrets, unlicensed data, installed dependencies or claims about real facilities without source/verification records. Synthetic fixtures should remain explicitly fictional.

Contributions use the repository's existing MIT licence for original code. Dependencies retain their own licences. Contributors must have the right to contribute their work.
